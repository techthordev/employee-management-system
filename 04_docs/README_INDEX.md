# Documentation Index (04_docs)

This folder is the **single entry point** for project documentation.

## Start Here

1. [`04_docs/CONSOLIDATED_DOCUMENTATION.md`](./CONSOLIDATED_DOCUMENTATION.md) `04_docs/` — unified project documentation (architecture, setup, auth flow, testing, roadmap).
2. [`04_docs/SOURCE_MAP.md`](./SOURCE_MAP.md) — mapping of original markdown sources and consolidation decisions.

## Documentation Rules

- New high-level documentation should be added to `CONSOLIDATED_DOCUMENTATION.md`.
- Legacy READMEs in module folders can remain for local context, but authoritative project guidance lives in `04_docs/`.
- Duplicate content should be removed from legacy files and replaced with links to `04_docs/README_INDEX.md`.
